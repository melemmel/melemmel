## About Me

As a full-stack developer and IT analyst programmer, I'm driven by a passion for solving complex problems through innovative technology. I specialize in building modern, scalable web applications using **Laravel, PHP, JavaScript, and MySQL**, with expertise spanning frontend, backend, mobile, and desktop development.

I'm committed to writing clean, maintainable code and creating solutions that deliver real impact. I thrive in collaborative environments and continuously expand my technical expertise while staying current with industry best practices.

**Location:** Pasay City, Metro Manila, Philippines  
**Open for:** Freelance Projects | Collaborations | Full-time Opportunities
